开源 · 无需账号或设备登记 · v0.3

让机密走自己的通道

Agent 需要密码时，不必让你贴进聊天。它发起一次申请，你在独立网页里填写；浏览器加密，发起电脑解密，直接交给任务程序。聊天里只留下状态和退出码。

添加到你的 Agent了解信任边界
示例

Agent 终端

$ secret-request --agent-name Codex \
    --name "测试库登录" \
    --purpose "查询测试库数据" \
    --fields-file fields.json \
    -- python query.py
# 已发送企微通知，等待本人填写…
# 已交付并执行，退出码 0

你的浏览器

测试库登录 Codex（自行声明）· 查询测试库数据 · 剩余 9 分 41 秒 用户名 密码•••••••••• 提交本次机密

申请在聊天里说明，机密在网页里交付

  1. 01

    Agent 发起申请

    说明用途和所需字段，由本机客户端发送企微通知。

  2. 02

    你确认并填写

    打开本次链接，核对用途后提交，也可以拒绝。浏览器先加密，再发送。

  3. 03

    本机程序执行

    客户端取回一次并解密，交给任务程序。短期会话可复用，任务结束后撤销。

从一个 skill 开始

适用于支持 Skills 的 Agent。安装后开启新会话，让 Agent 初始化 Secret Request 并配置企微通知。

$npx skills add zhaoxinbeizhucele/secret-request -g

需要 Node.js 22.20+ 与 Python 3.12+。企微 webhook 在本机配置，完整地址不要发进聊天。

使用公共服务

无需部署，使用本站中转。让 Agent 初始化并连接企微 webhook，就能发起申请。

https://secret-request.eicai.cc
无需 Docker 或域名

只在本机运行

让 Agent 选择本机模式并拉起服务器。填写链接只能在同一台电脑打开，停止进程即关闭服务。

secret-request-server
自己的主机与 HTTPS

部署自己的服务

用 GHCR 镜像和 Docker Compose 部署，再让 Agent 使用你的地址。桌面和手机都能填写。

服务保存什么
正常流程中只暂存加密输入，私钥留在发起电脑。没有申请历史数据库；领取一次即移除密文，重启后未交付的申请失效。
你仍需信任
提供输入网页的服务，以及本机执行任务的程序。被篡改的网页能在加密前读取输入；本机完整权限的程序也不受本工具隔离。
请留意
申请者名称由 Agent 自行声明。持有填写链接的人都可以提交或拒绝，请核对用途，不要随意转发。公共服务有限流，不承诺可用性；需要独立控制时请自建。
