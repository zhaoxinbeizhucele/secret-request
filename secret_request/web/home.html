从一个 skill 开始。

适用于支持 Skills 的 Agent。安装后开启新会话，让 Agent 初始化 Secret Request 并配置企微通知。

npx skills add zhaoxinbeizhucele/secret-request -g

需要 Node.js 22.20+ 与 Python 3.12+。企微 webhook 在本机配置，完整地址不要发进聊天。

使用公共服务

新安装默认

无需部署，使用本站中转。让 Agent 初始化并连接企微 webhook，就能发起申请。

https://secret-request.eicai.cc

只在本机运行

无需 Docker 或域名

让 Agent 选择本机模式并拉起服务器。填写链接在同一台电脑打开，停止进程即关闭服务。

secret-request-server

部署自己的服务

自己的主机与 HTTPS

使用 GHCR 镜像和 Docker Compose 部署，再让 Agent 使用你的服务地址。支持桌面和手机填写。

中转的是密文。
信任边界也要讲清楚。

正常流程中，服务仅暂存加密输入，私钥留在发起电脑。服务不建申请历史数据库；领取一次即移除密文，重启会使未交付申请失效。

你仍需信任提供输入网页的服务，以及本机执行任务的程序。被篡改的网页能在加密前读取输入，本机完整权限的程序也不受本工具隔离。

申请者名称由 Agent 自行声明。填写链接持有者可以提交或拒绝，请核对用途，不要随意转发。公共服务提供有界限流，无可用性承诺；需要独立控制时可以自建。
